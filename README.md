# SuperDrive
SuperDrive is a program that uses the Ross Video Floor Director API to help manage lower-third (super) playout in an OverDrive environment. There are three basic requirements:
1. Lower thirds must be primary events in OverDrive, not secondary.
2. Lower third MOS objects must all have the same file name (I.E. "XPN 1 MOS CG").
3. FloorDirector active in your OverDrive environment.

The first super on any given line in a rundown will be automatically played out by SuperDrive emulating a Spacebar press.

Further documentation can be found in the PDF located [here](./documentation/documentation.pdf).
